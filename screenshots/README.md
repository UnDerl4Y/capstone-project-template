# Application Screenshots

This directory contains screenshots demonstrating the application's interface, implemented features, workflows, and outputs.

## Screenshot Guidelines

- Include clear and relevant screenshots of the working application.
- Capture important interfaces, agent interactions, workflows, input data, and generated outputs.
- Ensure screenshots are readable and demonstrate the actual implementation.
- Avoid duplicate, irrelevant, or unnecessary screenshots.
- Do not include API keys, passwords, access tokens, or other sensitive information.

## Naming Convention

Use descriptive filenames that clearly identify the feature, component, or workflow shown in the screenshot.

**Recommended format:**

`feature_or_component_description.png`

**Examples:**

```text
foundry_agent_workflow.png
document_upload_interface.png
legal_clause_extraction.png
credit_financial_analysis.png
credit_limit_recommendation.png
manager_approval_workflow.png
application_dashboard.png
```

Use `.png` or `.jpg` formats and choose filenames that make the screenshot content easy to identify.
